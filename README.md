## 🗺️ Что это за проект

HOI4 Focus Studio — редактор деревьев национальных фокусов **Hearts of Iron IV**. Можно создавать фокусы, перемещать их по сетке, проводить связи и экспортировать заготовку дерева для мода.

В проекте доступны **веб-версия и приложения для трёх ОС**:

| Версия | Формат | Требования |
|---|---|---|
| **GitHub Pages** | Сайт / PWA | Современный браузер |
| **Windows 10/11 x64** | `.exe`, установщик `.exe` | Microsoft Edge |
| **macOS 11+** | `.app` в ZIP, Intel + Apple Silicon | Chrome / Edge / Brave для отдельного окна, либо браузер по умолчанию |
| **Linux x86-64 / ARM64** | `.deb` и портативный `.tar.gz` | Chrome / Chromium / Edge / Brave или браузер через `xdg-open` |

Все версии **не требуют аккаунта, API-ключей, интернета для работы с редактором и Node.js**. Для публикации сайта и загрузки установочных файлов, конечно, потребуется сеть.

## 🍎 Установка на macOS (Intel и Apple Silicon)

**Файл:** `HOI4-Focus-Studio-macOS-universal.zip`.

1. Распакуй ZIP: внутри находится **`HOI4 Focus Studio.app`**.
2. Перетащи `.app` в папку **Программы / Applications**.
3. Запусти через Finder или Launchpad. При первом запуске macOS может потребовать разрешение.

Версия **универсальная**: содержит отдельные исполняемые файлы для Mac с процессорами Intel (`x86_64`) и Apple Silicon (`arm64`), а запуск автоматически выбирает правильный. Если установлен **Google Chrome**, **Microsoft Edge**, **Chromium** или **Brave**, редактор откроется в отдельном окне браузерного приложения. Если ничего из них не найдено, откроется обычная вкладка браузера по умолчанию (например, Safari). В последнем случае сохранения будут находиться в профиле этого браузера.

> Программа **не подписана Apple Developer ID и не нотарифицирована**. При блокировке macOS открой **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть** (*Open Anyway*) для проверенного файла. Не нужно отключать Gatekeeper целиком. Пакет использует локальный веб-сервер `127.0.0.1:38429` и не отправляет проекты в облако. Это не нативный редактор на Swift, а приложение-оболочка для браузера.

Если используется Chrome/Edge/Chromium/Brave в режиме отдельного окна, профиль сохраняется по пути `~/Library/Application Support/HOI4FocusStudio/BrowserProfile`. Перемещать `.app` можно без потери проектов: профиль расположен отдельно. Для переноса между браузерами скачай JSON-копию.

**DMG:** workflow `.github/workflows/build-macos-linux.yml` умеет собирать также `.dmg` на GitHub Actions с macOS runner. Готовый ZIP с `.app` доступен без дополнительной сборки.

## 🐧 Установка на Linux

Для Ubuntu, Debian, Linux Mint и других дистрибутивов с поддержкой DEB:

- **x86-64 (обычные ПК):** `HOI4-Focus-Studio-linux-amd64.deb`.
- **ARM64 / aarch64:** `HOI4-Focus-Studio-linux-arm64.deb`.

Открой скачанный `.deb` в менеджере пакетов либо установи командой:

```bash
sudo apt install ./HOI4-Focus-Studio-linux-amd64.deb
```

После установки найдёшь приложение **HOI4 Focus Studio** в меню программ. Из терминала оно запускается командой `hoi4-focus-studio`. Удаление: `sudo apt remove hoi4-focus-studio`.

**Без установки (любые совместимые дистрибутивы):** распакуй `HOI4-Focus-Studio-linux-amd64-portable.tar.gz` или ARM64-аналог и запусти бинарник из распакованной папки:

```bash
./HOI4-Focus-Studio
```

Нужен установленный браузер. Если найден Chrome, Chromium, Edge или Brave, откроется отдельное окно с изолированным профилем; в остальных случаях приложение попробует открыть сайт в обычном браузере через `xdg-open`. Linux сохраняет профиль Chromium-браузера в `~/.config/HOI4FocusStudio/BrowserProfile` (или в соответствующем каталоге `$XDG_CONFIG_HOME`). При запуске через браузер по умолчанию используется его собственный профиль.

> Программа работает полностью локально и не требует подключения к интернету. `.deb` не подписан ключом пакета, поэтому устанавливай его только из доверенного источника. На Fedora, Arch и других системах без DEB используй портативный архив.

## 🪟 Установка на Windows

1. Открой [Releases](../../releases) репозитория или скачай приложенный дистрибутив.
2. Запусти **`HOI4-Focus-Studio-Setup.exe`**.
3. Подтверди установку и при желании создание ярлыка на рабочем столе.
4. Открой **HOI4 Focus Studio** через меню «Пуск».

**Без установки:** можно просто запустить `HOI4-Focus-Studio.exe`. Он сам запускает локальный редактор. В Windows-версии сайт встроен внутрь EXE; держать рядом `index.html` не нужно.

> Важно: это **не Electron**. Компактная Windows-оболочка запускает Microsoft Edge с отдельным профилем и локальным веб-сервером `127.0.0.1:38429`. Интернет не используется. Если Edge не установлен или порт занят, окно приложения может не открыться. EXE **не подписан сертификатом**, поэтому SmartScreen может запросить подтверждение запуска. Запускай файлы только из доверенного источника.

### Удаление Windows-версии

В Windows открой **Параметры → Приложения → HOI4 Focus Studio → Удалить** или запусти `Uninstall.exe` из папки программы. При удалении установщик спросит, оставить ли локальные сохранения.

### Где хранятся сохранения Windows

`%LOCALAPPDATA%\HOI4FocusStudio\BrowserProfile`

Это отдельный профиль Edge для редактора, а не папка установки. Повторная установка сохраняет проекты, если профиль не был удалён.


## ✨ Возможности редактора

- Создание, удаление, переименование и перемещение национальных фокусов.
- Настройка ID, названия, описания, координат, стоимости и иконки.
- Связи **И / ИЛИ** (`A, B` / `A|B`), взаимоисключающие фокусы.
- Несколько проектов и деревьев, дублирование проектов, поиск фокусов.
- Отмена и повтор изменений, контрольные версии проектов.
- Импорт деревьев `.txt`, описаний `goals.gfx` и файлов иконок; поддержка части DDS-текстур.
- Создание ветки из текстовой схемы.
- Экспорт файла фокусов `.txt`, русской локализации `.yml` с UTF-8 BOM, текстового плана для ИИ.
- Локальное автосохранение, резервные копии `.json` и восстановление из JSON.

## 💾 Сохранения и резервные копии

**Сохранение происходит автоматически** после изменений. Используется IndexedDB, с запасным вариантом localStorage.

Чтобы перенести проект на другой компьютер или между Windows, macOS, Linux и GitHub Pages:

1. В редакторе нажми **«↓ JSON-копия»** и сохрани файл.
2. На другом устройстве открой редактор → **«Проекты и сохранения» → «Открыть JSON»**.
3. Выбери скачанный `.json`.

Сохранения в разных браузерных профилях **не общие**: веб-версия хранит их в данных сайта браузера, настольная версия с Chromium-браузером — в своём локальном профиле. На одном устройстве сохраняй JSON для переноса между сайтами, браузерами и ОС. При очистке данных сайта или удалении профиля Edge несохранённые в JSON проекты могут исчезнуть. Регулярно скачивай резервные копии.

## 🎮 Экспорт в Hearts of Iron IV

**Экспорт HOI4** формирует заготовку `focus_tree` со связями, координатами, стоимостью и пустым `completion_reward`. Вручную настрой условия доступности дерева, теги стран и награды. Фокусам, использующим свои картинки, потребуются реальные файлы текстур `.dds` и определённые `spriteType` в моде.

**Редактор НЕ создаёт полностью готовый мод** и не проверяет всю семантику скриптов Paradox. Графические превью из проекта — не готовые игровые ресурсы.

|---|---|
| `Ctrl+S` | Скачать копию проекта JSON |
| `Ctrl+Z` | Отменить изменение |
| `Ctrl+Y` | Повторить изменение |
| `Delete` | Удалить выбранный фокус |
| `Esc` | Выйти из режима создания связи |

*HOI4 Focus Studio — неофициальный фанатский инструмент. Не связан с Paradox Interactive.*
