# HOI4 Focus Studio — GitHub Pages Edition

Редактор дерева национальных фокусов **Hearts of Iron IV** для бесплатного статического хостинга на **GitHub Pages**. Не требует Node.js, npm, сервера, API-ключей или сборки.

## Как опубликовать

1. Создай или открой репозиторий GitHub (желательно публичный, если используешь GitHub Free).
2. Загрузи **содержимое** этой папки в корень репозитория: `index.html`, `sw.js`, `manifest.webmanifest`, `icon.svg`, `.nojekyll` и `README.md`. **Не нужно** загружать архив ZIP как один файл.
3. Открой **Settings → Pages → Build and deployment**.
4. Выбери **Source: Deploy from a branch**, затем **Branch: main**, **Folder: /(root)** → **Save**.
5. Страница будет доступна по адресу `https://<username>.github.io/<repository>/` (для репозитория с именем `<username>.github.io` — в корне домена).

> Файл **index.html** должен лежать **в корне выбранной папки публикации** — не во вложенной папке после распаковки архива.

## Что умеет

- Создание и редактирование национальных фокусов; перетаскивание фокусов, связи AND/OR, взаимоисключения.
- Несколько **проектов** и несколько деревьев в проекте; переключение и дублирование.
- **Автосохранение** в браузере (IndexedDB с запасным вариантом localStorage); резервные JSON-копии, импорт JSON и восстановление контрольных версий.
- Отмена и повтор действий, поиск фокусов, ввод тега страны для экспорта.
- Импорт `.txt` деревьев HOI4, `.gfx`-описаний и папки игровых иконок; поддержка части DDS-форматов. Выбранные иконки сохраняются как небольшие картинки-превью.
- Экспорт национального дерева в HOI4 `.txt`, русской локализации `.yml` с UTF-8 BOM и текстового описания для ИИ.
- Возможность повторно открыть сайт без сети после загрузки (если браузер поддерживает service worker и уже сохранил ресурсы).

## Где хранятся сохранения

**Сохранения НЕ попадают в GitHub.** GitHub Pages обслуживает статические файлы, а проекты каждого пользователя остаются **локально в его браузере и на его устройстве**. Другой браузер, телефон, инкогнито или очистка данных сайта — другое/пустое хранилище.

**Рекомендуется регулярно нажимать «↓ JSON-копия»**. Восстановление: **Проекты и сохранения → Открыть JSON**. При перепубликации сайта сохранения на том же домене и пути обычно сохраняются, если не очищать данные сайта.

## Ограничения экспорта в HOI4

Это **редактор дерева**, а не полноценный генератор готового игрового мода. Он не создает автоматически `common/national_focus/`, `interface/` и все игровые ресурсы. Для собственных изображений требуется вручную добавить настоящие DDS-файлы и `spriteType` в мод. Экспорт `.txt` содержит заготовку `completion_reward = {}` и общую `country`-настройку с тегом, выбранным в панели. Отредактируй результаты под свой мод. Автогенерируемые графические превью в JSON не заменяют игровых текстур.

### Быстрые клавиши

- `Ctrl+S` / `Cmd+S` — скачать резервный JSON.
- `Ctrl+Z` и `Ctrl+Y` — отмена и повтор вне текстовых полей.
- `Delete` — удалить выделенный фокус.

## Технически

Весь редактор находится в `index.html`; дополнительные файлы используются для иконки, offline-кэша и отключения обработки Jekyll. Данные сохраняются только через браузерные API, без аналитики и подключений к внешним сервисам.
