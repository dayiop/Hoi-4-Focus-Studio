HOI4 Focus Studio — Windows Edition
===================================

Что это:
Редактор национальных фокусов Hearts of Iron IV для Windows 10/11 (x64).
Построен на локальном HTTP-сервере и Microsoft Edge в режиме отдельного окна.
В Интернет приложение не обращается. Требуется установленный Microsoft Edge.

Запуск:
Пуск → HOI4 Focus Studio

Где находятся сохранения:
%LOCALAPPDATA%\HOI4FocusStudio\BrowserProfile
Сохранения хранятся в IndexedDB/localStorage внутри отдельного профиля Edge.
Они не синхронизируются с версией на GitHub Pages.

Резервные копии:
В редакторе нажмите «↓ JSON-копия».
Для восстановления: «Проекты и сохранения» → «Открыть JSON».
Делайте копии перед переносом на другой компьютер или очисткой профиля.

Что экспортирует:
Дерево фокусов .txt для HOI4; русскую локализацию .yml; текст для ИИ.
Экспорт служит заготовкой и может требовать доработки файлов мода.

Удаление:
Параметры Windows → Приложения → HOI4 Focus Studio → Удалить
или запустите Uninstall.exe из папки установки.
Установщик позволяет сохранить или удалить локальные данные.

Сборка не подписана цифровым сертификатом; Windows SmartScreen может
предупредить о неизвестном издателе. Если есть сомнения, проверьте
исходный код в приложенном репозитории и соберите программу самостоятельно.
