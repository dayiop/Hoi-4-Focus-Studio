HOI4 Focus Studio - portable Linux version

1. Extract this archive.
2. Open a terminal in the extracted folder.
3. Run ./HOI4-Focus-Studio

Requirements: Linux x86_64 (amd64) or ARM64 (aarch64), and an installed browser.
Chrome, Chromium, Edge and Brave open as a standalone app window.
Other browsers can open via xdg-open in a normal browser tab.

Editor files are built into the executable; no internet or separate web server needed.
The editor starts a temporary localhost server (127.0.0.1:38429).
Projects are saved automatically in a persistent local browser profile.
Download JSON backup copies regularly.
